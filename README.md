# Codewars TypeScript

My solutions to Codewars problems while learning TypeScript.

I started this repository to keep track of the problems I've solved and to see how my code changes as I get better.

I try to solve every kata on my own first. After submitting it, I usually look through other solutions to find things I didn't know about TypeScript or just better ways to solve the same problem.
